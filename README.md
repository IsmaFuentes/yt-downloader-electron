# YouTube Audio Downloader

Aplicación de escritorio para descargar audio de vídeos de YouTube usando Electron, React y TypeScript.

## Funcionalidades

- Descarga automática del ejecutable `yt-dlp.exe` desde su release oficial.
- Descarga de audio en la mejor calidad disponible.
- Cola de descargas: añadir, eliminar y procesar varios vídeos.
- UI diseñada con Ant Design.

## Instalación

```bash
git clone <repo-url>
cd <repo-folder>
npm install
npm start      # Ejecutar en modo desarrollo
npm run make   # Compilar para producción
```
